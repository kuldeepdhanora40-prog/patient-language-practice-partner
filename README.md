# 🗣️ Patient Language Practice Partner

A friendly language-learning practice partner built for the **Hacktoberfest Weekend Challenge: Build for a Friend**.

## What it does

- Practice conversations in a chat-style interface
- Choose English, Spanish, or Hindi
- Choose a learning level
- Receive encouraging feedback
- Get practice tips
- Track a simple practice score
- Start a fresh practice session anytime

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local URL shown by Streamlit, usually `http://localhost:8501`.

## Tech

- Python
- Streamlit

## Note

This version uses lightweight rule-based feedback so it can run without an API key. An open-source AI model can be added as a next step for richer conversations and grammar correction.
